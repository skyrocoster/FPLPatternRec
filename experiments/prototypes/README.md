# Prototypes

Store isolated, temporary technical experiments here. Keep prototypes separate from production application code.

- [`dob-research/`](dob-research/README.md) — retained birth-date candidates and individual review notes.
- `player-team-audit/` — saved player/team audit tooling and evidence.

Group related files under their topic directory rather than adding loose research
outputs here. Reviewed runtime inputs belong in the pipeline's
[`reference/`](../../src/tools/data_pipeline/reference/README.md) package;
intermediate research records are not automatically approved ingestion evidence.
