# .opencode

Repository-local OpenCode workflow assets.

- `agents/` — agent definitions
- `skills/` — reusable workflows
- `commands/` — repository commands
- `plugin/` and `tools/` — OpenCode extensions

Root configuration lives in [`opencode.jsonc`](../opencode.jsonc). The full
maintenance runner is documented in
[`docs/FULL_TEST_PROCESS.md`](../docs/FULL_TEST_PROCESS.md).
